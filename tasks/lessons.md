## 04.09.2026 — коммит при красном тесте
Цепочка `npx vitest run | grep … && git commit` маскирует exit code vitest: grep успешен, коммит уходит с падающим тестом. Правило: перед коммитом проверять код возврата самого vitest (`npx vitest run >/dev/null && …`), а grep для вывода запускать отдельно.

## 04.09.2026 — свайп внутри скролл-контейнера на iOS Safari
Рабочий рецепт (подтверждён на устройстве): touch-события на треке, `touchmove` с `passive: false`, `touch-action: pan-y`, направление фиксировать самим на первых 3px при угле ≤45°, `preventDefault` только если `e.cancelable`, и НИКОГДА не считать неотменяемый move вертикальным — внутри overflow-скроллера Safari помечает все move неотменяемыми. Pointer-события не годятся: Safari отзывает указатель при малейшем уходе пальца по вертикали (работает «через раз»). `inert` на соседних панелях не ставить: после снятия Safari продолжает игнорировать касания. Скорость рывка считать по окну ~100 мс, а не по двум последним событиям.
